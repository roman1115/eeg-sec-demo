## Overview

This project presents an EEG-guided speech emotion conversion framework that incorporates emotional representations extracted from EEG signals into speech emotion conversion.

The framework introduces EEG emotional information through:

- Cross-modal knowledge distillation
- EEG emotion representation learning
- Conditional speech emotion generation

This work explores the feasibility of using EEG-derived emotional representations as conditioning inputs for speech emotion conversion.
